# 故事地图视觉组件

这些文件只负责美术呈现；故事数据、布局、推演和详情卡仍由 `../test-page.mjs` 管理。

- `water-surface.mjs` / `.css`：8K 记忆星图背景与原有 WebGL 局部折射。沿用预览的 400 地图像素半径、90% 折射强度和默认 36% 的视觉比例；正式地图缩放时，波纹半径随地图倍率变化。背景取样中心会停在图片的安全边缘，避免地图大幅平移时拉伸最后一行或最后一列像素。悬停节点或轻点空白背景产生一次折射，选中节点持续产生折射。WebGL 不可用时显示同一张静态星图。
- `light-beams.mjs` / `.css`：每条故事边生成 8 根紧密交错的冷灰蓝光丝；当前路径转为象牙白与暖金色，独立 SVG 图层只移动一段渐变高光。视口外的高光暂停绘制。`createStoryBeams(edges, onSelect)` 接受现有布局的边，在地图位置变化时调用每条 `beam.paint(from, to)`。
- `node-ripples.css`：起点、普通、选中、结局和深度上限使用不同的星痕标记；选中节点使用暖金星核，背景折射由水面组件继续提供。
- `memory-star-ui.css`：正式故事地图的暗色顶部操作、右侧“故事走向”路径卡片栏和底部地图工具。卡片按当前节点的祖先路径排列，不参与地图布局。

详情卡的打开状态通过 `test-page.mjs` 的 `openPanels` 传给水面组件；关闭详情时，节点的持续波纹和该路径的流动高光一起停止。系统要求减少动态效果时，节点和连接仍保留静态高亮。
